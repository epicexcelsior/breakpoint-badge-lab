# Product

## Platform

Embedded hardware: Solana BP26 badge, running stock Solana OS. The local browser demo runs the firmware emulator.

## Users and purpose

Conference attendees need useful social tools with a short, visible demo and minimal onboarding.
The apps must stay useful at meetups and after Breakpoint.

## Stack

Lua 5.5 apps, Python standard-library tooling, and Node.js firmware automation. The user delegated implementation choices.

## Priorities

- One button starts the main experience.
- Two nearby users demonstrate Sideband's value.
- No account or server operated by this project is required on a physical badge.
- Automated checks run without a connected device.
- Hardware claims require hardware evidence.

## Open limits

The physical badge is unavailable. App Store publication requires the owner's badge-portal session with linked X.
USB audio is unavailable through the board's CH340C serial bridge.
