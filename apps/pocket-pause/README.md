# Pocket Pause

One quiet minute, or a focused block of time.

Press SELECT to start the default one-minute breathing guide.
The guide uses four seconds in and six seconds out, without holds. Follow a comfortable pace.

Before starting:

- UP/DOWN changes between breathing and focus.
- LEFT/RIGHT changes duration.
- Breathing offers 1, 3, or 5 minutes. Focus offers 5, 15, or 25 minutes.

While running, SELECT pauses or resumes. BACK stops and returns to settings.
RIGHT toggles optional soft lights. Lights start off. The app has no sound or strobing.
The timer stops when the app closes. It does not run as a background service.

The app saves mode and duration only. It has no network connection or project account.
Permissions: `led`, used only after the lights toggle.
